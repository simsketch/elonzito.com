# /chat RAG Chatbot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a public RAG chatbot at `elonzito.com/chat` that answers questions about Elon Zito from a curated, sanitized corpus using hybrid retrieval, deployed on Vercel.

**Architecture:** Hand-authored markdown corpus → heading-aware chunks → embeddings precomputed at build time and committed → request-time hybrid retrieval (cosine + BM25, fused by RRF) → streamed answer from Vercel AI Gateway. Retrieval logic is pure and takes the embedding function as a parameter, so the whole path is testable offline.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, Vercel AI SDK (`ai`, `@ai-sdk/gateway`, `@ai-sdk/react`), Vitest, Tailwind 3.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-10-chat-rag-design.md`. It governs; this plan implements it.
- `TOP_K = 6`, `RRF_K = 60` — exported constants in `lib/chat/retrieve.ts`, never env vars.
- Chat model default `google/gemini-2.5-flash-lite`; embedding model default `google/gemini-embedding-001`. Both overridable by `CHAT_MODEL` / `EMBEDDING_MODEL`.
- Input caps: question ≤ 500 chars, history ≤ 6 turns, `maxOutputTokens: 500`.
- Rate limit: 10 messages / 10 minutes / IP, in-memory.
- Tailwind: use registered color utilities (`bg-bone/95`, `border-ink/10`). NEVER `[var(--color-*)]/N` — it compiles to invalid CSS in Tailwind v3 and renders transparent.
- Corpus must never contain: `NEEC3-`, `NADP-`, `ESAR`, `Indigo Reef`, `Cedar Flats`, `Maple Creek`, `Q-139`.
- No test may perform a network call.
- Branch: `feat/chat-rag`. Commit after each task.
